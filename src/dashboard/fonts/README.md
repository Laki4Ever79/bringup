# Dashboard fonts

Vendored so the page needs no CDN. All three are under the SIL Open Font License 1.1 (the `OFL-*.txt` next to
each). Subset to Latin and arrows with fontTools `pyftsubset`, as WOFF, from github.com/google/fonts (`ofl/`).

| File | Family | Use |
|---|---|---|
| BigShouldersDisplay.woff | Big Shoulders Display (variable weight) | display: headlines, big numbers |
| InstrumentSans.woff | Instrument Sans (variable width and weight) | body text |
| JetBrainsMono.woff | JetBrains Mono (variable weight) | fields, refs, pins, revisions |
